# Mjolnir Mod

Mjolnir Mod is a Minecraft mod for Fabric loader version 1.21.11 that adds Mjölnir, Thor's Hammer, with custom mechanics and abilities. This mod includes a powerful weapon and pickaxe combined, with unique abilities such as Lightning Strike, Returning to Hand, Flight/Levitation, and a Worthiness Check feature.

## Install

1. Install the Fabric loader version 1.21.11.
2. Download the Mjolnir Mod jar file.
3. Place the jar file in the mods folder of your Minecraft installation.

## Use

1. Craft Mjölnir using rare end-game materials (Netherite Ingots and Echo Shards) in an anvil or crafting table.
2. Use the item to activate abilities:
   - Right-click or shift-right-click to summon a lightning bolt at the targeted block or entity within a 30-block range.
   - Throw the hammer to deal impact damage and have it automatically return to your inventory or hand after a short delay.
   - Hold the hammer while airborne to glide or soar short distances by spinning it.
3. Complete the Worthiness Check to unlock all abilities.
